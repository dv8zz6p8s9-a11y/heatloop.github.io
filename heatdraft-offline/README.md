# HeatDraft — robocza strona offline

Pliki umieszczono na **oddzielnej gałęzi** `heatdraft-offline-draft`, aby nie zmieniać działającej wersji beta HeatLoop ani publikowanej strony GitHub Pages.

Otwórz `index.html` lokalnie w przeglądarce. Nazwę marki i adres kontaktowy zmienisz w `config.js`.

**HeatDraft to nazwa robocza.** Przed publicznym użyciem konieczna jest weryfikacja praw do nazwy. Nie scalaj tej gałęzi z `main`, dopóki strona ma pozostać nieopublikowana.
