# HeatLoop — test izolowany

Otwórz `index.html` lokalnie lub opublikuj katalog `heatloop-test` osobnym hostingiem testowym. Jeśli katalog znajduje się w publikowanej gałęzi GitHub Pages, również jest publicznie dostępny. To historyczny prototyp, a nie aktualna aplikacja BETA.

Ten podgląd zawiera walidację liczb z przecinkiem, możliwość wyczyszczenia pól i ponownego wpisania, orientacyjne obliczenie mocy pomieszczeń, orientacyjny podział pętli z limitem 80 m wraz z podejściami, zestawienie i podstawową wycenę oraz podgląd PNG/JPG. Wyniki wymagają sprawdzenia hydraulicznego.

Nie jest to pełna aplikacja HeatLoop B. Zaawansowana edycja rysunków, PDF i dobór hydrauliczny znajdują się w przygotowanej oddzielnie paczce. Nie należy zamieniać tego podglądu na produkcyjną wersję bez testów.

Aktualna wersja jest rozwijana w katalogu `heatloop-b/`; tego prototypu nie należy używać zamiast niej.
