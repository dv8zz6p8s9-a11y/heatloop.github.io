To nie jest jeszcze generator ślimaka. Ten ekran pokazuje, jak prawdziwy kod Python sprawdza obrys pomieszczenia L, położenie przykładowej trasy i limit 80 m. Nie weryfikuje jeszcze rozstawu pomiędzy przebiegami ani promieni gięcia. Rysowane odcinki są demonstracyjne — nie wolno ich traktować jako projektu do montażu.
